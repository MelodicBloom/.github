## Creative Doctrine

Nine principles govern every system built here — not as aspiration but as constraint:

1. **Regenerative over Sustainable** — build systems that give back more than they take
2. **Hold Contradiction as Parameter** — tension is data, not error
3. **Socratic Recursive Inquiry** — question the frame before answering the question
4. **Community as Co-Author** — the audience shapes the work
5. **Pattern as Wisdom** — recurring structures carry knowledge
6. **Transparency of Architecture** — show the bones
7. **Launch to Independence** — every system should be able to run without its maker
8. **Joyful Experimentalism** — play is a valid methodology
9. **Design for the Long Arc** — optimize for decade-scale, not launch-day metrics
