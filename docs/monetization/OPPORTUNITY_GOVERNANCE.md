# Opportunity, Conversion, Affiliate, Ads, and Generative Media Governance

## Required proposal package

Every proposal must state the evidence, target audience, need, value exchange, user journey position, implementation slice, alternatives, risks, unknowns, measurements, stopping conditions, privacy/accessibility implications, and approval gate.

## Conversion hooks

A conversion proposal must define the event, denominator, attribution window, lead-quality measure, user benefit, friction introduced, accessibility behavior, guardrail metrics, and removal condition. Dark patterns, deceptive urgency, preselected consent, and obstruction of core content are forbidden.

## Affiliate marketing

Affiliate placement requires explicit disclosure, product relevance, evidence of user benefit, merchant/network terms review, link-health monitoring, non-deceptive placement, and separation from editorial judgment. AI may recommend candidates but may not enroll accounts or publish links.

## Advertising

Ad integration requires a named provider, consent/data-flow map, privacy review, age/context suitability, layout stability, performance budget, accessibility review, frequency limits, brand-safety rules, revenue denominator, and a kill switch. Paid spend and campaign publication require human approval.

## Generative images and video

Each asset retains model/tool, prompt and negative-prompt hashes, seed/settings when available, source/reference rights, generation date, editor history, human review, accessibility text, intended license, and product usage. No asset is treated as rights-cleared merely because a model generated it.

## Generative code and components

Generated code enters through a draft PR with allowed paths, tests, build evidence, accessibility checks, dependency review, security review where applicable, and rollback. Generated code never receives direct production authority.
